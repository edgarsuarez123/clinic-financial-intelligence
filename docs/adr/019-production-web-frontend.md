# Streamlit is temporary; custom web frontend is required

Status: Accepted user clarification during Phase 3

Decision: Maintain one cumulative backend/workspace. Use Streamlit for local testing and demonstrations. Deliver a custom production web frontend containing login, dashboards, visualizations, analytics, simulations and natural-language questions before launch. It must consume the existing FastAPI capabilities and server-side authorization.

Consequences: The final frontend framework and scheduling are not yet selected. Finishing Streamlit does not satisfy the production-frontend milestone. This clarification supersedes any interpretation of Streamlit v1 as the final shipped UI, while preserving the current backend phase work.
