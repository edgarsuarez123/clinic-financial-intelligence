# Screenshots

Place portfolio screenshots here after running the app locally.

Suggested filenames used by the root README:
- `overview.png` — financial dashboard with KPI metrics and charts
- `revenue.png` — revenue explorer with insurer/category/provider breakdowns
- `clarity.png` — Ask Clarity chat interface with a sample question and answer
- `budgets.png` — budget workspace with scenario comparison

Run the demo environment (see [how-to-run.md](../../how-to-run.md)) to generate
synthetic data, then take screenshots at `http://localhost:3000`.
